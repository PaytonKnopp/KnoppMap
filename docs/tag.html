Place Tagger

Name the places, pick a cover photo, add a story. Your edits save in this browser as you go.

How to publish your changes
  1. Click Download places.json.
  2. On GitHub, open the repo → config folder → Add file → Upload files, drop the file in and commit to main (it replaces the old one). Or just send the file to Claude.
  3. Ask Claude to "rebuild the map" (or run python3 build/build.py) so the family map picks it up.

Tips: click photos to select them, then use Move selected to put them in another place or New place to split them off. ⭐ sets the cover photo. Drag a pin on the map to move a place. Places marked Claude's guess were named from the photos — please check them.
